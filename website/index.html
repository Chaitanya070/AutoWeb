READY WHEN YOU ARE

Get started in a few steps.

AutoWeb is not listed in the browser stores yet. Download the team build and load it as an unpacked extension.

01

Download

Choose Chrome or Edge above. Both buttons download the same compatible extension package.

02

Unzip the package

Extract AutoWeb-Chrome.zip into a folder that you can keep on your computer.

03

Load the extension

Open chrome://extensions or edge://extensions, turn on Developer mode, choose Load unpacked, and select the extracted folder containing manifest.json.

04

Connect your model

Open AutoWeb, visit Settings, add a provider, choose a Navigator model, and optionally choose a separate Planner model.

i

For your teammates: share this Vercel URL. They can download the same package and install it locally. Each teammate configures their own model provider and API key.

GOOD TO KNOW

A few quick
answers.

Is AutoWeb in the Chrome Web Store?

Not currently. This page provides an unpacked extension ZIP, which you install from the browser's Extensions page with Developer mode enabled.

Does the Vercel website run the extension?

No. Vercel hosts this download and information page. The extension runs in each teammate's browser after they install it.

Do teammates share an API key?

No. Every teammate configures their own provider and model inside the extension. Avoid sharing API keys through the website or chat.

What browsers are supported?

The project targets Chrome and Edge. Other browsers are not officially supported.
