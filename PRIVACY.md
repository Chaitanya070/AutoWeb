# Privacy Policy for AutoWeb

## Introduction

AutoWeb is an open-source AI web automation Chrome extension. This Privacy Policy explains how we
handle your data and protect your privacy.

## Open Source

AutoWeb is licensed under the Apache License 2.0, and its full source code is available for
review, ensuring complete transparency.

## Data Collection and Processing

### Local Processing
- AutoWeb operates entirely within your browser
- Login credentials and cookies never leave your browser
- All user data is processed locally by default

### Anonymous Analytics (Optional)
**Analytics is enabled by default but can be disabled anytime** in extension settings. No
analytics are actually collected unless the maintainer running your build has configured an
analytics endpoint.

**We collect only, when enabled:**
- Task metrics (execution times, error categories)
- Domain names visited (e.g., "amazon.com" - not full URLs)
- Anonymous usage statistics
- Anonymous user identifier (randomly generated)

**We never collect:**
- Personal information, credentials, or authentication data
- Full URLs, page content, screenshots, or task instructions
- Any personally identifiable information

Analytics data, when enabled, is anonymized and used solely to improve the extension. It is never
sold or shared with advertisers.

### LLM Provider Interactions
When using AI features, web page data (screenshots and HTML) is sent directly to your chosen LLM
provider (for example, Google Gemini). This is necessary for AI functionality. Your data privacy
is subject to your chosen LLM provider's policies.

## API Keys
- You provide your own API keys for LLM providers
- Keys are stored locally in your browser only
- You manage key security per provider terms

## User Control
- Clear conversation history and settings anytime
- Enable/disable analytics through extension options
- Uninstall the extension to remove all local data

## Changes to This Privacy Policy
We may update this policy periodically. Please review it regularly for changes.
